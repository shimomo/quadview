Terms and privacy

Terms

QuadView uses YouTube API Services. By using QuadView you agree to be bound by the YouTube Terms of Service. Videos are shown with YouTube's embedded player.

What this page collects

This page itself collects no personal information and runs no analytics. It sends nothing about you to the server that hosts this page.

What is stored in your browser

  • The preset URLs (including whether each is hidden), the YouTube API key and your language choice are stored in this browser's localStorage. "Remove" and "Clear" in Settings delete them, and so does clearing the browser's site data.
  • The API key is used only for requests to YouTube (www.googleapis.com) and is sent nowhere else.
  • The list of streams found for a channel preset, and the state of each video of a video preset (video ID, title, start time, whether it is live), are kept in this browser's sessionStorage for 15 minutes, only to display them. They disappear when the tab is closed.
  • URLs you paste are not stored.

YouTube and Google

The embedded YouTube player and YouTube API Services are provided by Google. The player may store information such as cookies on your device or read information from it. Google handles information according to the Google Privacy Policy. You can revoke access through an API key by deleting the key in the Google Cloud console.
