利用条件とプライバシー

利用条件

QuadView は YouTube API Services を使っています。QuadView を使うことで、 YouTube 利用規約に同意したものとみなされます。 映像は YouTube の埋め込みプレーヤーで表示しています。

このページが集める情報

このページ自身は、個人情報を集めません。アクセス解析もしていません。 このページを配信しているサーバーに、あなたの情報を送ることはありません。

ブラウザに保存するもの

  • プリセットの URLとYouTube API キーを、このブラウザの localStorage に保存します。設定の「外す」「消す」で消せます。ブラウザのサイトデータを消しても消えます。
  • API キーは、YouTube（www.googleapis.com）への問い合わせにだけ使い、ほかには送りません。
  • チャンネルのプリセットで探した配信の一覧（動画 ID、タイトル、開始時刻）は、表示のためだけに、このブラウザの sessionStorage に15分だけ置きます。タブを閉じると消えます。
  • 貼り付けた URL は保存しません。

YouTube と Google について

埋め込みの YouTube プレーヤーと YouTube API Services は Google が提供しています。プレーヤーは、お使いの端末にクッキーなどの情報を保存したり、端末から情報を読み取ったりすることがあります。 Google による情報の扱いは、Google のプライバシーポリシーに従います。 API キーを通じたアクセスの取り消しは、Google Cloud のコンソールでキーを削除することでできます。
