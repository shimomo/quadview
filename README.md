# QuadView

[English](README.en.md)

YouTube の動画やライブを、1つの画面に最大4枠で並べて見るツールです。
同じ時間帯に、いくつものライブ（複数会場のスポーツ、ゲーム大会の各配信など）を、タブを切り替えずに追えます。

<https://shimomo.github.io/quadview/>

- 画面の大きさに合わせて、スクロールなしで4枠を最大の大きさに並べます。
- 枠を入れ替えても、ほかの枠の映像は止まりません。
- 音はミュートで始まります。音は各枠の YouTube プレーヤーで操作してください。
- ノート PC などの横長の画面を想定しています。

## 使い方

1. **URL を貼る**: YouTube の動画やライブの URL を貼ると、空いている枠に入ります。
2. **プリセットを足す**: 「設定」から、プリセット（候補の一覧、JSON）の URL を足すと、上の帯に候補のボタンが並びます。押すと枠に入り、もう一度押すと外れます。プリセットはいくつでも足せて、このブラウザが覚えています。使わないプリセットは、設定の「表示」を外すと帯から隠せます（読み込んだまま、隠したプリセットは自動で枠に入れません）。
3. **API キーを入れる**（任意）: チャンネルのプリセットは、あなた自身の YouTube Data API キーで、そのチャンネルの「今日の配信」（ライブ中・これから始まるもの）を探します。見つかった配信は「LIVE」「20:00〜」付きのボタンになり、開いたときにライブ中の配信から順に4枠が埋まります。
   動画のプリセットも、キーがあれば今の状態を確かめ、ライブ中なら「LIVE」、終わった配信なら「終了」を付けます（動画のプリセットは、自動では枠に入れません）。

### API キーの作り方

1. [Google Cloud のコンソール](https://console.cloud.google.com/apis/credentials)でプロジェクトを作り、「YouTube Data API v3」を有効にします。
2. 「認証情報」で API キーを作ります。
3. キーに制限をかけます。
   - アプリケーションの制限: 「ウェブサイト」で `https://shimomo.github.io/*`
   - API の制限: 「YouTube Data API v3」だけ
4. QuadView の「設定」に貼ります。

キーはこのブラウザにだけ保存し、YouTube（`www.googleapis.com`）への問い合わせにだけ使います。
帯の「探し直す」を押すと、15分のキャッシュを待たずに、今の配信を問い合わせ直します（枠の映像はそのまま。押すたびに、開いたときと同じだけクォータを使います）。
検索は1チャンネルあたり約2ユニット（`pages` が多いチャンネルはページ数 × 約2ユニット）で、結果はこのタブに15分だけ置きます（無料枠は1日 10,000 ユニット）。

プリセットのせいでページが固まったときは、`https://shimomo.github.io/quadview/?safe` を開くと、プリセットを読み込まずに開けます。「設定」から外してください。

## プリセットの形

プリセットは、ブラウザから読める（CORS が許可された）JSON です。GitHub Pages などに置けます。
どちらの形にも、YouTube API から取ったデータは入れません（人が書いた設定だけ）。

### 動画のプリセット（キー不要。キーがあれば LIVE・終了を表示）

```json
{
  "name": "表示名",
  "items": [
    { "label": "ボタンの名前", "video_id": "11文字の動画 ID", "title": "ツールチップ（任意）" }
  ]
}
```

### チャンネルのプリセット（キーが必要）

```json
{
  "name": "会場",
  "timezone": "Asia/Tokyo",
  "search": {
    "channels": [
      { "id": "UC…（西会場のチャンネル）", "default": "西" },
      { "id": "UC…（複数の会場を流すチャンネル）", "priority": 1, "pages": 4 }
    ],
    "exclude": ["予告"],
    "strip": ["[^\\s【】]{1,6}?主催"],
    "after": "(?<![A-Za-z])in(?![A-Za-z])",
    "duplicates": "first"
  },
  "items": [
    { "label": "西", "aliases": ["西会場", "西"] },
    { "label": "南", "aliases": ["南"] },
    { "label": "番組", "aliases": ["生配信"], "auto": false }
  ]
}
```

各チャンネルの最新50件（`pages` を指定すると 50件 × pages、最大10ページ）の中から、`timezone`（省略時はブラウザ）で**今日**のライブ中・予約中の配信（埋め込みが許可されているもの）を探し、タイトルで候補に振り分けます。

1. タイトルに `exclude` の言葉があれば除きます。
2. `strip` の正規表現に合う部分を取り除きます。
3. `after` に合う部分があれば、その後ろだけを見ます（「北 in 南」なら「南」）。
4. 配信したチャンネルの `default` の候補の `aliases` が含まれていれば、その候補。
5. なければ、`aliases` がタイトルの一番前に出てくる候補。
6. どれもなければ、チャンネルの `default` の候補（なければ除く）。

同じ候補に配信が複数あるときは、チャンネルの `priority`（大きいほど先。省略時は 0）、その候補を `default` に持つチャンネル、ライブ中、開始が早い、の順に並べ、`duplicates` が `"first"`（省略時）なら先頭だけ、`"all"` ならすべて（「南」「南 ②」…）をボタンにします。
アップロード一覧は動画が作られた順に並ぶので、配信の予約枠をずっと前に作っておくチャンネルは、`pages` を増やさないと今日の配信まで届きません。
ページを開いたときに自動で枠に入るのは、各候補の先頭の配信だけです（「②」以降と、`"auto": false` の候補は、ボタンからだけ入れられます）。
正規表現は JavaScript の形で、大文字小文字を区別しません。`exclude` と `aliases` は、ただの文字列の包含です。

## 言語

画面は日本語と English に対応しています。初めて開いたときはブラウザの言語に合わせ、バーの言語選択で切り替えられます（選んだ言語はこのブラウザが覚えます）。
プリセットに書いた名前やラベルは翻訳されません。

## プライバシー

このページ自身は個人情報を集めず、アクセス解析もしません。詳しくは[利用条件とプライバシー](https://shimomo.github.io/quadview/privacy.html)を見てください。
QuadView は YouTube API Services を使っています。使うことで [YouTube 利用規約](https://www.youtube.com/t/terms)に同意したものとみなされます。

## 開発

依存はありません。`npm test`（Node 24 の `node --test`）でロジックのテストを動かします。
`site/` をそのまま静的に配信すれば動きます（例: `python3 -m http.server -d site`）。
